# auto-welearner

WE Learn 课程页自动翻页辅助脚本，当前版本 **3.0.0**。在同一个课程标签页内等待设定时间、播放本页音视频，再点击网站原生的“下一节”按钮。提供可拖动面板、暂停与继续，以及同源标签页之间的控制权互斥。

**当前翻页条件是“停留时间达到设置值，并且检测到的媒体已播完”，尚未校验课件原生完成状态。停留或播放结束不等于满足阅读、作答、提交等全部学习要求。** 实际学时、完成度和成绩由平台判定，本脚本不提供有效入账或避免记录撤销的保证。

## 安装与更新

1. 在新版 Edge 或 Chrome 中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 [welearn-autopager.user.js 安装链接](https://raw.githubusercontent.com/MINGBuBai23/auto-welearner/main/welearn-autopager.user.js)，在扩展安装页中确认安装。若浏览器只显示源码，可在 Tampermonkey 中新建脚本，将文件全文粘贴进去并保存。
3. 更新时替换已有脚本，避免将多个版本同时启用。关闭旧版本的学习辅助程序，并只保留一个学习课件页面。
4. 进入 `https://welearn.sflep.com/Student/StudyCourse.aspx` 课程页。脚本在课程外层页面显示面板，初始位置为左下角；首次进入默认启用。

若没有出现面板，检查扩展的站点访问权限、用户脚本是否启用，以及当前是否为带有 `contentFrame` 的课程学习页。

## 功能

| 功能 | 当前行为 |
| --- | --- |
| 原生翻页 | 点击外层课程页的 `NextSCO()` 链接，保留网站自己的结束当前课件、校验和进入下一节流程 |
| 停留设置 | 默认每节停留 20 秒，额外等待随机 0～9 秒；已有配置优先保留 |
| 媒体等待 | 尝试播放检测到的音视频，等其结束后才自动翻页；浏览器禁止自动播放时需手动点播放 |
| 单一控制器 | 只有外层课程页可以翻页，子框架只报告媒体状态并接受播放授权 |
| 标签页互斥 | 使用 Web Locks，同源且运行此脚本的标签页中只允许一个持有控制权；不支持时停止自动操作 |
| 网站提示 | 检测到多开、人工验证、锁定或会话失效等提示时暂停，并保留网站原始弹窗 |
| 翻页超时 | 点击后 30 秒内未确认加载则暂停，不自动补点 |
| 停留恢复 | 在同一标签页内保存当前小节的本地停留计数；本地计数不代表平台已记录学时 |
| 可拖动面板 | 拖动标题栏移动，保存位置；限制在视口内，并支持复位与键盘移动 |

## 面板操作

- **移动**：按住标题栏拖动。点击“复位”返回左下角。
- **键盘移动**：让标题栏获得焦点后，方向键移动 10 像素，`Shift` 加方向键移动 40 像素，`Home` 复位。
- **停留**：支持 `20`（秒）、`29m`（分钟）、`1h`（小时）。
- **随机≤**：设置额外等待的上限；填 `0` 表示不增加随机等待。
- **应用设置**：点击“应用”，或在时间输入框中按回车。设置保存在浏览器本地。
- **暂停 / 继续**：控制本脚本的播放与翻页操作。继续不会解除网站验证或恢复已经结束的平台会话。
- **下一节**：手动点击网站原生下一节按钮，会跳过本脚本的停留和媒体等待条件。
- **开 / 关**：切换脚本功能开关。

快捷键：

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl + Alt + S` | 暂停 / 继续 |
| `Ctrl + Alt + A` | 开 / 关 |

本版没有旧版的按钮拾取、强制点击、诊断快捷键或 Python 运行方式。

## 工作流程

1. 从课程目录选中项识别当前小节，避免依赖页内切换后可能保持不变的地址栏参数。
2. 获取同源 Web Lock，只有持有者执行自动操作。
3. 等待课件加载，累计本地停留时间，并汇总同源及已注入脚本的跨域框架媒体状态。
4. 达到停留时间且媒体结束后，点击网站已有的下一节链接。
5. 等待目录及课件加载确认；遇到网站提示、不可用按钮或加载超时则停止自动推进。

课件的会话、计时、学习票据和学习记录仍由网站原生代码处理。脚本不直接调用学习记录写入接口，不修改完成状态、分数或作答明细，也不禁用平台心跳、活动检测或人工验证。

## 已知限制

- **尚未按完成度判断翻页**：阅读、练习、提交等任务需要按课件要求完成；脚本不会自动答题。
- **标签页互斥有范围限制**：只能协调同源、同浏览器存储环境中运行本版脚本的页面，不能限制旧工具、其他浏览器或其他设备的学习会话。
- **播放可能需要手动启动**：浏览器自动播放策略、课件自定义播放器、延迟加载或未注入脚本的跨域框架，都可能导致等待。检测到多个未结束媒体时也可能持续等待。
- **后台与休眠影响运行**：页面冻结或系统睡眠可能停止脚本执行；超过 15 秒的单次定时器间隔不会整段补入本地停留计数。网站自己的计时仍以平台为准。
- **适配范围有限**：当前针对 `StudyCourse.aspx`、`contentFrame` 和现有课程目录结构；其他课件布局、目录分组或站点改版可能需要调整。
- **异常提示需要处理**：人工验证需在网站中完成；平台已结束会话时，需返回课程重新进入。
- **验证状态**：已通过 `node --check` JavaScript 语法检查；尚未完成当前版本在已登录网站中的实际拖动、连续翻页及平台记录验证。

## 本地检查

```sh
node --check welearn-autopager.user.js
```

此命令只检查语法，不会启动浏览器或访问学习接口，也不能替代真实页面验证。

## 3.0.0 版本变化

- 使用网站原生下一节入口，由外层课程页统一控制翻页。
- 使用 Web Locks 协调同源标签页，遇到平台异常提示暂停。
- 加入独立拖动标题栏、位置保存、视口边界限制、复位和键盘移动。
- 跨域框架通过校验消息来源的 `postMessage` 同步播放授权与媒体状态。
- 点击后等待加载确认，超时暂停；系统睡眠或页面冻结后不补算整段本地停留。
