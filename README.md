# auto-welearner

WE Learn 课程页自动翻页与完成度辅助脚本，当前版本 **3.3.4**。脚本在同一课程标签页内提供“时长模式”和“完成度模式”，可在课件页内读取课件自带的答案，完成填空、选择、判断、勾选等题目后走网站原生提交流程。

**自动作答默认关闭。** 首次安装只启用停留、媒体等待和翻页；需要作答时在面板中手动勾选“自动作答”。

**完成度、正确率、学习时长是三个独立指标：**

- **完成度** = 已完成进度项数 ÷ 全部进度项数。`noprogress` 项目不参与计算；`notscored` 项目仍计入完成度；填空题只要去掉首尾空白后非空就算完成，答对与否另行判断。
- **正确率** = 计分项目实际得分 ÷ 计分项目总权重。只有计分项目参与正确率，不计分的主观输入不影响正确率。
- **学习时长** 是脚本在本地单独累计的停留时间，只用于面板展示和记录，不等于平台记录的学时。

## 自动提交闸门

脚本填空后**不会只凭完成度 100% 就提交**。客观题必须同时满足以下条件：

1. 完成度达到 100%；
2. 没有缺失答案或无法解析的题目（`no-key`、`no-answer`、`no-controller`、`error`）；
3. 正确率达到面板设置的下限，默认 **100%**。

任何一条不满足时，脚本暂停自动提交，面板显示“已拦截：正确率 83% 低于 100%”之类的提示，等待人工核对；不会把低正确率或缺失答案的作答提交上去。用户可以在面板把“正确率≥”调低，例如允许 80% 的部分得分。

提交期间脚本会在每次等待后、点击 Submit 前、确认弹窗出现后、点击“继续提交”前重新检查：完成度、缺答案、正确率，以及自动作答开关、脚本开关、父页面授权（7 秒有效期）、网站警告和当前课件身份。确认弹窗出现后如果答案被改动导致正确率跌破阈值，脚本会关闭弹窗并放弃本次提交。暂停、关闭自动作答、切换页面或授权过期同样会中止尚未确认的提交。

## 进度上报与历史记录

课件 iframe 的只读进度采集与自动作答是分开的：即使关闭“自动作答”，脚本仍每秒读取并上报完成度、正确率、提交状态和未完成项，面板不会停留在“等待课件”。关闭自动作答只影响填答和提交，不影响进度显示。

进度报告带有每次文档加载生成的 `docId`、课件 URL 和课件 ID，并与当前目录小节绑定。切换目录时脚本保存旧小节实际使用的 `docId`/URL，清除当前进度并立即把授权改为 `allow:false`；旧 iframe 的同一份报告会被拒绝，在提交中的任务也会中止。只有出现新的 `docId`、课件地址变化或 iframe 在切换后重新加载时，才恢复对新课件的授权和进度接收。自动翻页后再手动切换目录同样适用，旧课件的 100% 不会写给新小节，也不会用于放行新小节翻页。

如果切换时还没有收到过旧小节的进度（没有旧 `docId`/URL 可对照），脚本不会接受任何迟到报告，而是等待切换后 iframe 源变化并真正完成加载；同源重载不会被当成新章节。`sectionSwitching` 不会按时间自动解除，只有明确的新课件确认才会恢复。同一次章节切换只初始化一次；iframe 内路由变化的新进度即使在下一次定时检查前到达，也不会被再次重置。

原生翻页前会保存旧课件身份、iframe 源和预期下一小节。iframe 换源并加载完成，或收到与旧课件明确不同的进度身份/路由后，才确认加载。目录选中标记支持放在小节 `li` 或其子元素上；标记没有同步时，脚本在本地把已确认的新课件绑定到预期下一节，不修改网站目录或完成标记。目录稍后同步不会再次重置停留和进度。仅目录变化、同地址重载、迟到首报或旧报告都不能确认翻页；30 秒无有效确认则暂停并持续撤销授权，点击“继续”只重新等待，不补点。

历史记录只接受两种可验证的完成状态：

- 引擎确认网站原生 Submit 已生效（`submitted = true`）；
- 外层课程目录出现 `course_disable` 完成标记。

无交互页、`et-checking` 页不会仅凭页面类型提前记为完成，必须等到目录标记出现；如果提交失败或页面提前关闭，不会留下虚假的完成记录。

## 已有答案保留

自动填答默认**不覆盖已经填写的答案**：

- 已填的填空、已选的选项、已勾选的项目保留原样；
- 组合填空只补空着的子空；
- 取不到课件答案或参考文本时不写入任何占位句，标记“缺答案”并阻止自动提交；
- 已有答案若导致正确率低于阈值，脚本暂停并提示人工处理，不会擅自改掉用户的答案。

## 安装与更新

1. 在新版 Edge 或 Chrome 中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 [welearn-autopager.user.js 安装链接](https://raw.githubusercontent.com/MINGBuBai23/auto-welearner/main/welearn-autopager.user.js)，在扩展安装页中确认安装。若浏览器只显示源码，可在 Tampermonkey 中新建脚本，将文件全文粘贴进去并保存。
3. 更新时替换已有脚本，避免将多个版本同时启用。关闭旧版本的学习辅助程序，并只保留一个学习课件页面。
4. 从 3.2.0/3.2.1 升级时，停留时间、随机等待、模式和脚本开关会迁移；**自动作答会强制重置为关闭**，需要重新勾选。旧配置不会让新版静默保持自动提交。
5. 进入 `https://welearn.sflep.com/Student/StudyCourse.aspx` 课程页。脚本在课程外层页面显示面板，初始位置为左下角。

若没有出现面板，检查扩展的站点访问权限、用户脚本是否启用，以及当前是否为带有 `contentFrame` 的课程学习页。

## 功能

| 功能 | 当前行为 |
| --- | --- |
| 时长模式 | 按设定停留时间、媒体播放状态翻页；不把停留时间当成完成度 |
| 完成度模式 | 等待网站原生完成标记，或等课件引擎确认已提交且完成度 100% 后再翻页 |
| 自动作答 | 默认关闭；开启后读取组件答案填入，满足闸门才提交，已填答案保留 |
| 人工语音页 | 检测到未完成的录音/跟读/口语/摄像头项时，只挂设定停留时长，不要求完成度或提交，直接进入下一节 |
| 完成度核算 | 直接读取课件 `etItem` 的 `cmi.progress_measure`，面板显示完成比例与未完成项 |
| 正确率核算 | 直接读取课件计算出的 `cmi.score.scaled`，按计分权重统计，不计分项不参与 |
| 学习时长 | 本页停留与本地累计分开记录；系统睡眠造成的长间隔不补算 |
| 原生翻页 | 点击外层课程页的 `NextSCO()` 链接，保留网站自己的结束当前课件、校验和进入下一节流程 |
| 停留设置 | 默认每节停留 20 秒，额外等待随机 0～9 秒；已有配置优先保留 |
| 媒体等待 | 自动播放检测到的音视频并静音（静音是浏览器允许无手势自动播放的关键），失败每 4 秒重试；普通 DOM 与 Shadow DOM 媒体会一起计数，全部播完才翻页 |
| 单一控制器 | 只有外层课程页可以翻页，子框架只报告媒体、完成度和正确率 |
| 标签页互斥 | 使用 Web Locks，同源且运行此脚本的标签页中只允许一个持有控制权 |
| 网站提示 | 检测到多开、人工验证、锁定或会话失效等提示时暂停，并保留网站原始弹窗 |
| 翻页超时 | 点击后 30 秒内未确认加载则暂停，不自动补点 |
| 可拖动面板 | 拖动标题栏移动，保存位置；限制在视口内，并支持复位与键盘移动 |

## 面板操作

- **移动**：按住标题栏拖动。点击“复位”返回左下角。
- **模式**：选择“时长模式”或“完成度模式”。完成度模式只有在网站标记完成或引擎确认提交且完成度 100% 后才翻页。
- **自动作答**：默认关闭；勾选后才读取答案并尝试提交，取消后只做停留、媒体等待和翻页。
- **自动静音播放媒体**：默认开启；切换开关会立即作用于当前正在播放的媒体，关闭后已静音的媒体会恢复声音。
- **正确率≥**：自动提交所需的最低正确率，默认 `100`；可填 `0-100`，填 `0` 表示不限制正确率。
- **键盘移动**：让标题栏获得焦点后，方向键移动 10 像素，`Shift` 加方向键移动 40 像素，`Home` 复位。
- **停留**：支持 `20`（秒）、`29m`（分钟）、`1h`（小时）。
- **随机≤**：设置额外等待的上限；填 `0` 表示不增加随机等待。
- **应用设置**：点击“应用”，或在输入框中按回车。设置保存在浏览器本地。
- **暂停 / 继续**：暂停会中止尚未确认的自动提交；继续不会解除网站验证或恢复已经结束的平台会话。
- **下一节**：手动点击网站原生下一节按钮，会跳过本脚本的停留和媒体等待条件。
- **开 / 关**：切换脚本功能开关。

快捷键：

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl + Alt + S` | 暂停 / 继续 |
| `Ctrl + Alt + A` | 开 / 关 |

## 完成度与正确率怎么算

课件页的 `etItem` 按下面的方式汇总（与网站源码一致）：

```text
完成度 = 已完成进度项数 / 全部进度项数
正确率 = 计分项目得分之和 / 计分项目总权重 × 100%
```

- `noprogress` 标记的组件及其子组件不计入分母。
- `notscored` 标记的组件仍计入完成度分母，但不进入正确率的权重。
- 填空组件的 `isCompleted` 只看输入内容去掉首尾空白后是否非空；答对由 `key` 另行判定。
- 多选题按 `each` / `exact` / `any` / `include` 等 `score-mode` 计算权重；组合填空、勾选题、判断题同理。
- 无交互页面没有进度项，课件在约 3 秒后自动标记完成；带 `et-checking` 的页面在初始化后自动标记完成。所以“停留 30 秒”不是所有页面统一的完成条件。
- 课件 `scormInfo.progressMeasure` 可能滞后于组件状态。面板显示的完成度取“网站值”和“本地 done/total”的较大者；如果本地已完成但网站仍是旧值，会同时显示“网站仍记录 x%”，避免卡在旧完成度。

面板会分别显示：

```text
完成度：100%（5/5 项）
正确率：100%（要求 ≥100%）
学习时长：本页 2秒 · 本地累计 2秒
自动作答：已提交
```

被闸门拦截时显示：

```text
正确率：83%（要求 ≥100%）
自动作答：已填 6/6，已拦截：正确率 83% 低于 100%
```

## 自动作答的范围

脚本在课件 iframe 内通过 AngularJS 组件控制器读取课件 HTML 里的答案，并按组件类型填入：

| 组件 | 处理方式 |
| --- | --- |
| `et-blank` | 填入 `key` 的首个可接受答案；已有内容保留；无答案且无参考文本时标记缺答案 |
| `et-multi-blank` | 只补空着的子空；`unordered` 由课件按集合判定 |
| `et-choice` | 按 `key` 选中对应选项，支持多选与 `max`；已有选择保留 |
| `et-tof` | 按 `key` 选择 T / F；已有选择保留 |
| `et-select` | 按 `key` 选择下拉项；已有选择保留 |
| `et-tick-blank` | 已勾选时保留原选择；未作答时勾选 `key` 指定的项目并补子空 |
| `et-writing` / `et-translate` | 有参考文本时填入；没有则标记缺答案 |
| `et-checking` / 无交互页 | 不操作，由课件自行提交 |

录音、跟读、口语、摄像头、媒体播放等需要真实设备或真实播放的组件不代做。遇到这类项目时，面板显示“X 项需人工”，脚本不提交未完成的小节，也不伪造录音或完成状态。

## 人工语音页

课件中只要还有未完成的 `et-recorder`、`et-talk`、`et-camera`、`et-follow-me` 项，脚本就把本节标记为“人工语音页”：

- 完成度模式不再要求 `course_disable` 或已提交，完成度低于 100% 也可以翻页；
- 不再等待媒体播完，按面板设置的停留时间（含随机等待）挂够后点击网站原生下一节；
- 不会提交未完成的作答，也不会写入完成历史；
- 面板显示“人工语音：N 项，按停留时长放行（不要求完成度）”。

如果网站的下一节入口在未完成时被锁定，脚本仍会提示“下一小节未开放”，这是平台侧限制。

## 工作流程

1. 外层课程页从目录叶节点识别当前小节，获取 Web Lock，等待课件加载。
2. 课件 iframe 收到外层授权后，读取 `etItem` 的进度项、答案键和完成状态；授权超过 7 秒未刷新即视为失效。
3. 只补未作答的项目，等待课件重新计算 `progress_measure` 与 `score.scaled`。
4. 完成度 100%、无缺答案、客观题正确率达到阈值时，点击网站原生 Submit，并在确认弹窗中点“继续提交”；每次等待后都复查开关、授权和课件身份。
5. 外层页收到完成度、正确率、提交状态后，按模式决定是否翻页；遇到人工项、闸门拦截、网站提示或加载超时则暂停。

课件的会话、计时、学习票据和学习记录仍由网站原生代码处理。脚本不直接调用学习记录写入接口，不修改平台返回的分数，也不禁用平台心跳、活动检测或人工验证。

## 已知限制

- **依赖课件内部结构**：自动作答依赖 `et-*` 组件和 AngularJS 控制器；课件改版、换教材或换播放器后可能需要调整。
- **录音类项目需人工**：`et-recorder`、`et-talk`、`et-camera`、`et-follow-me` 等需要真实设备，脚本只报告、不代做。
- **正确率阈值需要按课程设置**：默认 100% 适合答案完全确定的客观题；有部分得分规则的课程可在面板调低阈值。
- **完成度由网站最终决定**：面板显示的是课件当前状态；平台若另有校验，以平台结果为准。
- **标签页互斥有范围限制**：只能协调同源、同浏览器存储环境中运行本版脚本的页面。
- **播放可能需要手动启动**：浏览器自动播放策略、课件自定义播放器、延迟加载或未注入脚本的跨域框架都可能导致等待。
- **后台与休眠影响运行**：页面冻结或系统睡眠可能停止脚本执行；超过 15 秒的单次定时器间隔不会整段补入本地计时。
- **适配范围有限**：当前针对 `StudyCourse.aspx`、`contentFrame` 和 `et-*` 课件结构；其它布局或站点改版可能需要调整。

- 支持目录选中标记位于子链接；根据点击前的身份快照确认 iframe 换源加载或页内路由变化，并把进度绑定到下一小节。
- 捕获替换后的 iframe 加载事件；迟到的目录同步不再重置新课件进度。
- 保留 30 秒暂停和不补点；超时后持续撤销授权，旧报告、无效点击、原地重载不能解除等待。
- 新增离线浏览器导航回归，原有媒体结束不重播与进度隔离测试继续执行。

## 3.3.3 版本变化

- 修复课件在媒体结束后把播放位置归零，导致脚本反复重播、面板一直等待媒体播完的问题。
- 捕获媒体的 `ended` 事件并保留本次播放完成状态；媒体汇总、自动播放和 `et-media` 完成度读取使用同一状态。
- 换源、重新加载或课件路由变化时清除旧完成状态；同源、跨域 iframe 和 Shadow DOM 均覆盖。
- 新增 10 项离线媒体回归；Edge 真实课件测试等待音频自然结束，验证归零后不重播、停留满足后翻页一次。

## 3.3.2 版本变化

- 补齐 `et-talk`、`et-follow-me`、`et-camera` 的 AngularJS 控制器映射，修复已完成项目仍被标记为“需人工”的问题。
- 与课件原生状态一致：口语、摄像头按 `recordingCount > 0` 判定；跟读调用 `isCompleted()`，录制部分句子仍视为未完成。
- 已完成项目保留原值；未完成、控制器缺失或状态读取异常时仍标记为需人工。
- 新增离线浏览器回归 `tests/test_component_mapping.py`，覆盖状态转换、部分跟读、状态读取异常及已完成数据保留。

## 3.3.1 版本变化

## 3.2.10 版本变化

- “自动静音”开关立即生效：切换时直接修改当前所有媒体的 `muted`，不再只改配置等待下一次 `play()`；正在播放的媒体也会立刻静音/恢复。
- 媒体查找同时遍历普通 DOM 与 Shadow DOM，不再只在普通媒体为空时才扫描 shadow root；两者同时存在时都会进入播放与完成度判断。
- Edge 测试新增：播放中切换静音立即生效；普通 `<audio>` + Shadow DOM `<audio>` 两个媒体都静音、结束并触发 `NextSCO()`。

## 3.2.9 版本变化

- 媒体自动播放改为先静音再 `play()`，并处理 `playsinline`；避免 Edge/Chrome 因自动播放策略把音频/视频永久卡在暂停状态。
- 播放失败不再永久放弃，每 4 秒重试一次，媒体延迟加载或换源后仍会继续尝试。
- 新增“自动静音”开关，默认开启；关闭后不再强制静音，已静音的媒体会恢复声音。
- 媒体查找支持 Shadow DOM，覆盖把 `<audio>/<video>` 藏在 shadow root 里的自定义播放器。
- 新增 `tests/test_media_edge.py`：用本机 Microsoft Edge（Playwright `msedge` 渠道）加载公开课件，验证静音自动播放、媒体结束和原生 `NextSCO()`。

## 3.2.8 版本变化

- 完成度不再无条件优先使用 `scormInfo.progressMeasure`：取网站值与本地 `done/total` 的较大者，网站值滞后时面板也会反映实际作答进度。
- 面板在本地完成度领先时显示“网站仍记录 x%”，便于区分“脚本已填完”和“课件/平台尚未同步”。
- 新增 `stale-scorm-completion` 引擎测试：把 `progressMeasure` 固定为 0，8/10 时显示 80%，10/10 时显示 100%。

## 3.2.7 版本变化

- 没有旧 `docId`/URL 时，要求 iframe 源变化并完成加载才确认新章节；同源重载的迟到报告继续拒绝。
- 新增“切换 2.5 秒后同源重载仍拒绝、换 src 后才接受”的联动回归测试。

## 3.2.6 版本变化

- 章节切换改为一次性初始化（`switchKey`），目录观察与定时检查使用同一 `pageKey`；iframe 内路由变化的新进度在下一次 tick 前到达也不会被再次重置。

- 新增“自动翻页后手动切目录”和“切换时撤销旧 iframe 授权”两项联动回归测试。

## 3.2.4 版本变化
